# Optogenetic Intervention as a Potential Treatment for Borderline Personality Disorder

## Overview

Interdisciplinary Cognitive Systems research project exploring whether optogenetic memory modification could serve as a treatment for treatment-resistant Borderline Personality Disorder (BPD).

## Areas Explored

- Psychology
- Neuroscience
- Philosophy of Mind
- Research Ethics

## Research Components

- Literature Review
- Experimental Design
- Clinical Methodology
- Ethical Analysis

## Key Question

To what extent can optogenetics be utilized to address BPD symptoms in humans?
